# Roma Beauty & Jewellers
A mobile-friendly informational showcase website. No cart, online ordering or checkout.

## Update shop contact details
Edit `script.js` and fill in `SHOP_PHONE`, `SHOP_ADDRESS`, and optionally `SHOP_MAP_URL`.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the root of your GitHub repository. Go to Settings → Pages → Deploy from a branch → main → /(root) → Save. Wait for the published URL.

Product images are illustrative and load from Unsplash. Replace with your own shop/product photos before final publication for accuracy.
